FAQ

Is it really free?

Yes. The script, the recommendations and being recommended on other member sites cost nothing. There is no card to enter and no account to make.

Do you track my users?

No. No cookies, no tracking pixels, no analytics. The script makes one request: network.json from the same place the script is served. The streak and referral code are kept in your visitor's browser (localStorage) and never sent to us.

What apps will be shown on my site?

Only apps in the network, which we vet by hand. Same language as your page first, same category preferred, never your own app. The order rotates daily so every member gets seen. The full list is public in network.json.

How do I install with AI?

Tell your builder: "Add this script tag right before </body> on every page of my site" and paste the line. Ready-made prompts for each tool are on the install page.

What does it cost later?

Paid plans may come later for extras such as a dashboard. The core recommendation exchange stays free. If anything changes we'll tell you by email first.
